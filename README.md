# Flower Image Classification

## About the Project

This project aims to identify different types of flowers using image classification.

## Technologies Used

* Python
* Jupyter Notebook
* NumPy
* Matplotlib

## Project Structure

* data: Stores the flower image dataset.
* notebooks: Contains notebooks for coding and analysis.

## Project Workflow

1. Collect flower images.
2. Prepare the dataset.
3. Train an image classification model.
4. Test the model.
5. Predict flower types.
